# Job Tracker API

Uma API moderna para gerenciar vagas de emprego, construída com **Node.js**, **Express**, **TypeScript** e arquitetura modular.  

Status: **A+ Quality Setup** ✅

---

## 🛠 Tecnologias

- Node.js + Express
- TypeScript
- Zod (validação de dados)
- UUID (identificadores únicos)
- Prettier + ESLint (qualidade de código)
- Jest (testes unitários)
- TS-Node-Dev (desenvolvimento rápido com hot-reload)

---

## ⚡ Scripts

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Roda o servidor em modo desenvolvimento com hot-reload |
| `npm run build` | Compila TypeScript para JavaScript |
| `npm start` | Roda o servidor a partir da pasta `dist` |
| `npm run lint` | Verifica problemas de lint no código |
| `npm run lint:fix` | Corrige problemas de lint automaticamente |
| `npm run format` | Formata o código com Prettier |
| `npm run test` | Roda os testes com Jest (passa mesmo sem testes) |
| `npm run check` | Pipeline completa: format + lint + build + test |
